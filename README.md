**VAULTBREAK — Six Heists**: a complete top-down stealth heist game that runs offline in a desktop browser. Sneak past guards and their vision cones, dodge sweeping cameras and laser grids, crack the vault, grab the loot, and reach the getaway van. 6 missions with rising difficulty, 4 crew tools (lockpick, EMP, disguise, smoke), an alarm/heat meter with lockdown, lives, scoring with time and ghost bonuses, and clear win/lose states.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or open `game/index.html` directly from any static server — no build step, no network requests, all art drawn in code and all sounds synthesized with WebAudio.

## Controls

WASD / arrows move · SHIFT sneak · SPACE hold to crack vault / pick lock / hack panel · 1 lockpick · 2 EMP · 3 disguise · 4 smoke · P pause · M mute · R restart · mouse clicks buttons and tool chips.
